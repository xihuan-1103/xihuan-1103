## 二、百日攻坚总表（攻坚汇总 → 百日攻坚总表）

### 2.1 数据来源概述

| 来源 | 说明 |
|------|------|
| 基础信息配置 | 项目基础档案（区域、项目部、路段名称、总金额、工期起止） |
| 每日产值填报 | 日报逐日累计（产值、病害吨数、罩面吨数、施工天数、投入班组） |
| 月度计划倒排 | 周计划产值（用于计划完成率对比） |
| Excel 台账导入 | 当前版本以种子数据导入基础快照（金额/工效类），进度类字段按当前日期动态计算 |

### 2.2 字段取数明细（21 列，4 组）

#### 基本信息（A-E）

| 列 | 字段名 | 取数逻辑 | 来源模块 |
|:---|:-------|:---------|:---------|
| A | 序号 | 按区域内项目自然排序生成 | 基础信息配置（项目列表顺序） |
| B | 区域 | 项目档案中维护的区域归属 | 基础信息配置 → 项目区域字段 |
| C | 项目部 | 项目档案中维护的项目部归属 | 基础信息配置 → 项目部字段 |
| D | 路段/项目 | 项目档案中维护的路段或项目名称 | 基础信息配置 → 项目名称/路段简称 |
| E | 集团内外 | 项目归属分类（浙高运/沪杭甬/集团外） | 基础信息配置 → 集团内外属性 |

#### 金额进度（F-L）

| 列 | 字段名 | 取数逻辑 | 来源模块 |
|:---|:-------|:---------|:---------|
| F | 总金额（万元） | 项目合同总金额 | 基础信息配置 → 项目总金额 |
| G | 剩余金额（万元） | 总金额 − 累计完成金额 | 计算字段（F − H） |
| H | 累计完成（万元） | 基准日已完成产值 + 日报累计产值 | 每日产值填报（日报逐日累加） |
| I | 完成率 | 累计完成 ÷ 总金额 | 计算字段（H ÷ F） |
| J | 理论完成率 | 当前施工工期 ÷ 计划工期 =（当前日期 − 开工时间）÷（完工时间 − 开工时间）；**≥1 时封顶为 100%；无开工/完工时间显示 "/"** | 计算字段（基础信息配置 → 工期起止 + 当前日期，动态计算） |
| K | 进度偏差 | 完成率 − 理论完成率；完成率≥100% 显示"已完工"；无工期数据显示 "/" | 计算字段（I − J，动态计算） |
| L | 本周完成产值（万元） | 本周（周五~周四）日报产值合计 | 每日产值填报 → 按周区间汇总 |

#### 工效预警（M-Q）

| 列 | 字段名 | 取数逻辑 | 来源模块 |
|:---|:-------|:---------|:---------|
| M | 本周病害吨 | 本周（周五~周四）日报中病害类工程量吨数合计 | 每日产值填报 → 病害吨数按周汇总 |
| N | 本周罩面吨 | 本周（周五~周四）日报中罩面类工程量吨数合计 | 每日产值填报 → 罩面吨数按周汇总 |
| O | 本周病害日均工效（吨/天） | 本周病害吨数 ÷ 本周病害施工天数；施工天数=0 显示"无施工" | 计算字段（M ÷ 病害施工天数） |
| P | 本周罩面日均工效（吨/天） | 本周罩面吨数 ÷ 本周罩面施工天数；施工天数=0 显示"无施工" | 计算字段（N ÷ 罩面施工天数） |
| Q | 工效预警 | **① 病害：施工天数>0 且工效<300 → 病害工效偏低，≥300 → 正常；② 罩面：施工天数>0 且工效<800 → 罩面工效偏低，≥800 → 正常；③ 组合：两者都偏低 → "病害、罩面工效偏低"，其一偏低 → 对应预警，有施工且均正常 → "正常"，均无施工 → "无施工"** | 计算字段（O/P 与阈值比对，动态计算） |

#### 当前进度（动态计算，按最新数据）

| 列 | 字段名 | 取数逻辑 | 来源模块 |
|:---|:-------|:---------|:---------|
| — | 进度预警 | **① 完成率≥100% → 已完工；② 完成率<100% 且进度偏差≥0 → 正常施工（绿）；③ 偏差∈[-5%, 0) → 轻微滞后（黄）；④ 偏差∈[-10%, -5%) → 滞后（橙）；⑤ 偏差<-10% → 严重滞后（红）** | 计算字段（I/K 分级判定，动态计算） |
| — | 距完工天数 | 完工时间 − 当前日期（日历天数，负数=已逾期，红色显示）；已完工显示"已完成"；无完工时间显示 "/" | 计算字段（基础信息配置 → 完工日期 + 当前日期） |
| — | 还需天数 | 剩余金额 ÷ 开工以来日均产值（=累计完成 ÷ 开工已过天数）；未开工显示"待开工"，开工后无产值显示"无施工"，已完工显示"已完成" | 计算字段（G ÷ 日均产值，动态计算） |
| — | 能否按期 | 还需天数 ≤ 距完工天数 → "按期"，否则 → "滞后"；已完工显示"已完工" | 计算字段（还需天数与距完工天数比对） |

### 2.3 汇总层级

| 层级 | 内容 |
|:-----|:-----|
| 区域分组 | 按区域（杭州/湖州/嘉兴/绍兴/金衢/台州/丽水/温州/甬舟/省外/特种路面）分组，组头显示该区域项目数、总金额、累计完成、完成率、本周产值、按期/滞后/已完计数（**均按动态口径统计**：按期/滞后取"能否按期"动态判定，已完=完成率≥100%） |

## 三、数据看板 · 作战总览（Tab 1）

### 3.1 数据来源

| 来源 | 说明 |
|------|------|
| 基础信息配置 | 项目列表（区域、项目部、名称、总金额、工期起止、病害/罩面剩余工作日） |
| 每日产值填报 | 日报逐日累计（产值、吨数、施工天数、投入班组） |
| 月度计划倒排 | 周计划产值（用于计划完成率对比） |

### 3.2 核心指标（6 卡）

| 指标 | 取数逻辑 | 来源模块 |
|:-----|:---------|:---------|
| 总工程量（万元） | 全部项目合同总金额合计 | 基础信息配置 |
| 累计实际完成（万元） | Σ（基准日已完成产值 + 日报累计产值） | 每日产值填报 |
| 剩余产值（万元） | 总工程量 − 累计实际完成 | 计算字段 |
| 开累计划完成率 | （基准日已完成 + 截至当周周计划累计）÷ 总金额 | 月度计划倒排 |
| 进度滞后项目（个） | 实际完成率 < 计划完成率的项目数量 | 计算字段 |
| 班组缺口（区域） | 存在班组缺口（需求班组 > 可用班组）的区域数量 | 计算字段 |

### 3.3 今日战报（4 卡）

| 指标 | 取数逻辑 | 来源模块 |
|:-----|:---------|:---------|
| 当日完成产值 | 当日所有日报产值合计 | 每日产值填报 |
| 本周完成产值 | 本周（周五~周四）所有日报产值合计 | 每日产值填报 |
| 当日完成吨数 | 当日日报中病害+罩面+超薄吨数合计 | 每日产值填报 |
| 当日投入班组 | 当日日报中投入班组数合计 | 每日产值填报 |

### 3.4 多维对比（3 图）

| 图表 | 取数逻辑 | 来源模块 |
|:-----|:---------|:---------|
| 各区域 实际 vs 计划 完成率 | 按区域分组：实际完成率 = 区域累计完成 ÷ 区域总金额；计划完成率 = 区域累计计划 ÷ 区域总金额 | 基础信息配置 + 每日产值填报 + 月度计划倒排 |
| 各区域 剩余产值 | 按区域分组：区域总金额 − 区域累计完成 | 基础信息配置 + 每日产值填报 |
| 班组缺口 | 按区域分组：Σ（剩余工作日 ÷ 剩余工期 − 1），仅统计缺口 > 0 的项目 | 工期倒排 + 每日产值填报 |

### 3.5 区域作战看板（卡片）

| 指标 | 取数逻辑 | 来源模块 |
|:-----|:---------|:---------|
| 区域 | 全部区域去重 | 基础信息配置 |
| 实际完成率 | 区域累计完成 ÷ 区域总金额 | 每日产值填报 |
| 计划完成率 / 偏差 | 区域累计计划 ÷ 区域总金额；偏差 = 实际完成率 − 计划完成率 | 月度计划倒排 + 计算字段 |
| 剩余产值 | 区域总金额 − 区域累计完成 | 计算字段 |
| 剩余工期 | 区域项目剩余日历天数 | 工期倒排 |
| 班组缺 | Σ（剩余工作日 ÷ 剩余工期 − 1），仅统计缺口 > 0 的项目 | 工期倒排 + 每日产值填报 |
| 缺口标识 | 班组缺 > 0 → "⚠ 班组缺口"（橙框）；否则 "正常"（青框） | 计算字段 |

### 3.6 预警清单

> 取数范围：进度偏差 < 0 或 存在班组缺口的项目，按偏差升序排列。

| 列 | 取数逻辑 | 来源模块 |
|:---|:---------|:---------|
| 区域 / 项目部 / 项目 | 项目档案基础信息拼接 | 基础信息配置 |
| 类别 | 作业类型（病害 / 罩面 / 超薄等） | 基础信息配置 → 作业类型 |
| 实际% / 计划% / 偏差 | 同 3.4 口径（项目级） | 每日产值填报 + 月度计划倒排 |
| 剩余（万元） | 项目总金额 − 累计完成 | 计算字段 |
| 缺口工日 | 剩余工作日 − 剩余日历工期（>0 才显示，否则 "—"） | 计算字段 |
| 班组缺余 | 缺口工日 ÷ 剩余工期 折算班组数（>0 显示"缺 N 个"，否则 "充足"） | 计算字段 |
| 需求 / 可用（工日） | 剩余工作日 / 剩余日历工期 | 工期倒排 + 每日产值填报 |
| 最晚完工 | 项目计划完工日期 | 基础信息配置 → 工期起止 |

## 五、关键计算口径汇总

| 口径 | 公式 | 涉及模块 |
|:-----|:-----|:---------|
| 实际完成率 | （基准日已完成产值 + 日报累计产值）÷ 项目总金额 | 每日产值填报 |
| 计划完成率 | （基准日已完成产值 + 截至当周周计划累计）÷ 项目总金额 | 月度计划倒排 |
| 工期完成率 | 已过工期日历天数 ÷ 总工期天数 | 工期倒排 |
| 理论完成率（总表） | （当前日期 − 开工时间）÷（完工时间 − 开工时间），≥1 封顶，无工期数据显示 "/" | 计算字段 |
| 进度偏差（总表） | 完成率 − 理论完成率；完成率≥100% 显示"已完工" | 计算字段 |
| 进度预警（总表） | 已完工（完成率≥100%）/ 正常施工（偏差≥0，绿）/ 轻微滞后（[-5%,0)，黄）/ 滞后（[-10%,-5%)，橙）/ 严重滞后（<-10%，红） | 计算字段 |
| 工效预警（总表） | 病害：施工天数>0 且工效<300 → 偏低；罩面：施工天数>0 且工效<800 → 偏低；两者都偏低 → "病害、罩面工效偏低"，均无施工 → "无施工" | 计算字段 |
| 距完工天数（总表） | 完工时间 − 当前日期（负数=已逾期）；已完工 → "已完成" | 计算字段 |
| 还需天数（总表） | 剩余金额 ÷（累计完成 ÷ 开工已过天数） | 计算字段 |
| 能否按期（总表） | 还需天数 ≤ 距完工天数 → 按期，否则 → 滞后 | 计算字段 |
| 进度偏差（看板） | 实际完成率 − 计划完成率 | — |
| 工期进度偏差（看板） | 实际完成率 − 工期完成率 | — |
| 本周工效 | 本周（周五~周四）Σ吨数 ÷ Σ施工天数 | 每日产值填报 |
| 能否按期（看板） | 开工以来日均产值 × 剩余工期 ≥ 剩余产值 | 每日产值填报 + 工期倒排 |
| 班组缺口 | 剩余工作日 ÷ 剩余日历工期 − 1（单班组口径） | 工期倒排 |
| 进度预警分级（看板） | 已完成（≥100%）/ 红（<-20%）/ 黄（-20%~0）/ 绿（≥0） | — |
